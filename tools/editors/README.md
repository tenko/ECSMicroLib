# Editor Support

Without a language server the editor support is rather limited compared to
other languages. I have found [cudatext](https://cudatext.github.io/) simplest
to customize and use this editor daily.

[cudatext](https://cudatext.github.io/) setup has support for:
- Syntaxt highlighting
- Procedure outline tree
- Completion

There is also a setup for the [micro](https://cudatext.github.io/) editor which
